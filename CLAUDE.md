## Project-specific: API.md line endings

`API.md` is generated by `npx projen build` (jsii-docgen). Run on this Windows box it differs from CI (Linux), and the release job fails on `git diff --ignore-space-at-eol --exit-code`. Two causes, both seen in F026:

1. The working file comes out with CRLF line endings. Fix: `sed -i 's/\r$//' API.md`.
2. Multi-line JSDoc `@default` text (e.g. `ActionDogfoodOptions` "tells you to / declare a scenario", `sonarProjectKey` "SonarCloud / uses") is emitted with a stray interior `\r` where the source wraps. `--ignore-space-at-eol` does not hide it, and CI joins the lines with a single space. Fix: replace the interior CR with nothing, leaving a single space (`grep -c $'\r' API.md` must print 0).

After every build that regenerates `API.md`, run both fixes, then confirm `git diff --ignore-space-at-eol API.md` contains only intended changes. Do not hand-edit API.md otherwise.
